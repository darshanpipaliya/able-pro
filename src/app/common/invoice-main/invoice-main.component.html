Charge Codes that Need Rules

Each of these charge detail records in this grid have Charge Codes that we NOT used to determine which Vendor Product belong to what Service Number(s) and can be distributed now. Either a distribution rule needs to be assigned to the charge detail record, Status = Needs Rule. Utilize the Add/Edit icon to create a new rule or review the existing rule for the Charge Code.

 Distribution Rules by Event

These Charge Codes have a Distribution Rule assigned and the rule has been executed or are being executed. Utilize the Edit icon to review the existing rule for the Charge Code and the View icon to view the detail of the distribution.
