Locations
The charges and inventory count for a location are based on the most recent completed billing period, which typically reflects a full month's spending. "Current Charges" refer to the latest full billing period, while "Previous Charges" refer to the billing period before that.
For example, if today is September 15th, "Current Charges" would cover August, and "Previous Charges" would cover July.
