Rule Conditions

Distribution Level is how the rule will be applied AND where the rules are applied in the sequence listed below.  Multiple rules cannot run on a single charge record, the system will only process 1 rule per charge record.

  1. Customer Specific - Rules that are applied to a Specific Customer anywhere when choosing a specific set of value(s) either in Distribution Level or Distribution Method to distribute charges. These value(s) are only present for a particular customer.
  2. Customer Global - Rules that are applied to a Specific Customer but not hold specific value(s) for either Distribution Level or Distribution Method. These rules ONLY affect specific customers that have the specific charge code that the rule applies to.
  3. Vendor Global- Rules that are applied only to Vendor Billing Alias, but we do not hold specific value(s) for either Distribution Level or Distribution Method. These rules affect ALL customers that have the specific charge code from a Vendor Billing Alias that the rule applies to.
{{item.Type}} Distribution Level is required

Distribution Type refers to the method used in our formula to allocate costs to Billing ID(s) and/or Vendor Product(s). Some Charge Codes—specifically those with a Charge Code Type of Product, Feature, Usage, or Equipment—must be distributed before assigning a Vendor Product, using Billing ID Count or Billing ID Totals. Other distribution rules can be applied after a Vendor Product is assigned, using Vendor Product Totals as the Distribution Type.
{{item.label}} {{item.label == '% of Vendor Product' ? ' *' : ''}} Distribution Type is required

Distribution Origin tells the system where to look, in this case the origin account, for the particular charge code that the rule is built against. Basically, where is this charge code showing up on the invoice.

  1. Any Account - Rules with this will look for a specific Charge Code.
  2. Any Payable Account - Rules with this will look for a specific Charge Code that came in on any Payable Account to distribute. This can be used in Distribution Types that are Global. Payable is defined as the account we sent the check for which could be a Main or Sub Account depending on the vendor.
  3. Specific Payable Account - Rules with this will look for a specific Charge Code that came in on a specific Payable Account to distribute. This can only be used with the Distribution Type that is Customer Specific.
  4. Any Sub Account - Rules with this will look for a specific Charge Code that came in on any Sub Account to distribute. This can be used in Distribution Types that are Global.
  5. Specific Sub Account - Rules with this will look for a specific Charge Code that came in on a specific Billing Sub Account to distribute. This can only be used with Distribution Types that are Customer Specific.
  6. Any Service Number - Rules with this will look for a specific Charge Code that came in on any Service Number to distribute. This can be used in Distribution Types that are Global.
  7. Specific Service Number - Rules with this will look for a specific Charge Code that came in on a specific Service Number to distribute. This can only be used with the Distribution Type that is Customer Specific.
Distribution Origin is required

Distribution Method tells the system where to distribute the Charge Code for the rule.

  1. Payable Account (all inventory/accounts) - This will distribute the specific Charge Code to all Service Number(s) or Vendor Products in the Payable Account, based on Distribution Type, on a particular invoice. This can be used in Distribution Types that are Global.
  2. Origin Account - This will distribute the specific Charge Code to all Service Number(s) or Vendor Products, based on Distribution Type, that is tied to the account that the charge originated on. This can be used in Distribution Types that are Global.
  3. Specific Sub Account - This will distribute the specific Charge Code to all Service Number(s) or Vendor Products, based on Distribution Type, which are tied to that specific Sub Account This can only be used with Distribution Types that are Customer Specific.
  4. Specific Service Number - This will distribute the specific Charge Code to the specific Service Number(s) or Vendor Products tied to that Service Number based on the Distribution Type selected. This can only be used with Distribution Types that are Customer Specific.
Distribution Method is required

By opting to include Service Numbers from the inventory that aren't listed on the invoice for a distribution rule, those Service Numbers will be appended to the invoice. This allows the customer to see the charges on the Service Number's they represent vs the Vendors lump sum bill.
