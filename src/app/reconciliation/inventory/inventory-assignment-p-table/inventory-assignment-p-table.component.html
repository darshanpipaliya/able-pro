A Service Number is called a Billing ID in the system until it's linked with a person or location. Billing ID(s) that are newly added to the system and lack an assigned Primary Person or Location require Reconciliation. All Vendor Products are associated with Billing ID(s), which must be integrated into the inventory and linked with a person or location for allocation, approval, and payment. Reconciliation can be carried out individually for each Billing ID or collectively by selecting multiple Billing ID(s). In order to do bulk reconciliation the Billing ID(s) selected need to be on the same Vendor Product.

Opting for bulk reconciliation will result in all Billing ID(s) displayed on the page being assigned to the same person or location.
