All Billing IDs must be assigned to either a Person or a Location. If multiple Billing IDs are selected from the Reconciliation grid, all Billing IDs displayed on this page will be assigned to the same Person or Location chosen.

To exclude a Billing ID from the assignment, simply uncheck the checkbox next to it in the grid. Any unselected Billing IDs will return to the main Reconciliation grid and will still require assignment.

Assignment Guidelines
Billing ID assignments are typically determined by the type of service:

  • Person-based services (e.g., Mobile Services, Conferencing) are usually assigned to the individual responsible for them.
  • Location-based services (e.g., Internet Circuits, PBX Voice Services) are generally assigned to a physical location.

However, the system allows flexibility for assignments that deviate from these conventions. If a different assignment is required, simply switch to the appropriate tab and proceed with the assignment.

Bulk Assignment with "Assign All"
The Assign All option enables efficient bulk assignment by applying the selected Person or Location to all records in view, eliminating the need for individual updates.
