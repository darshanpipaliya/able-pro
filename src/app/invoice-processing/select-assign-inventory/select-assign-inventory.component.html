Select Inventory

When a vendor bills a single product across two separate accounts, it can be complicated. For example, access for a circuit might be billed on one invoice and account, while the ports are billed on another invoice and account. This page will help you consolidate these into a single vendor product.

Select a vendor product in inventory that is being billed on another account to add the additional charge codes from the current invoice. The vendor product must be associated with the same vendor and VBA to create a unified product. Use the grid below to add the new charge codes to the existing vendor product in inventory

Assignment

This grid is here to allows us to do 2 things. First it allows the ability to select a vendor product to be assigned to charge records when the charge records on a billing id are not the correct charge records to identify a vendor product. Second it allows us to build parent child relationships with inventory when we have billing ids on 2 separate payable account numbers that make up a single vendor product.
