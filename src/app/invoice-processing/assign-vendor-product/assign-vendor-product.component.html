 Detailed Inventory Selection

Add/Edit Vendor Product: Select all charge codes that are part of the Vendor Product needing to be added to the inventory. When defining a Vendor Product, you must select at least one charge code as the Parent or Primary Charge Code. This Charge Code should best represent the Vendor Product, such as access for a circuit or plan information for a mobile device. Other Charge Codes may also represent the Vendor Product, such as usage charges or features activated because the product exists, like a B-Channel on an ISDN or a texting feature for a mobile device but are not the Primary or Parent Charge Code.

Required Charge Codes mean the Vendor Product cannot be assigned without these codes. For example, an ISDN vendor product must have at least one B-Channel because an ISDN cannot function without it, making the B-Channel Charge Code required but not the Parent or the Primary Charge Code.

Optional Charge Codes mean the Vendor Product can exist even if these Charge Codes are not always present. For instance, a mobile device plan may include domestic data, voice, and messaging, but actual usage may vary. If usage is part of the Vendor Product but may or may not occur, then a usage Charge Code should not be listed as required.

The parent selected serves two distinct purposes:

  1. When multiple Billing IDs are part of a Vendor Product, the system creates a Parent/Child relationship between the Billing IDs. The parent inventory item is set to match the Billing ID with the primary Charge Code selected for the Vendor Product.
  2. If it is the parent of the Vendor Products Charge Code Group. Charge Codes listed are part of a charge code group that constitutes the Vendor Product. One Charge Code must be the Primary or Parent Charge code for the group. Additionally, each Charge Code can be marked as required or optional. Optional charge codes are for items that may not always be present in an invoice, such as Usage, which may vary each month.
