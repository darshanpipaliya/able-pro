All Charge Codes found must be assigned in the system to move forward in the invoice publishing process. The correct Charge Code assignment will help standardize the product structure and produce valuable reporting for customers.

If a Parent Charge Code was not found, an assignment will need to be created for the New Charge Code. Select the values to assign to the New Charge Code and edit the Display Name and Description to help ensure the most accurate data for customers. Display Name will be used in the system for the Charge Code Name.

Certain types of Charge Codes will need a distribution rule set up to distribute the charges. These are called Adjustments and Account Level Charges and do not directly total to the Current Charges for the inventory as provided by the carrier. Sometimes, these charges reference an inventory item but are not directly distributed to the current charges on the inventory in the invoice by the carrier. These charges will always need a distribution rule. In some cases, the system will manage the distribution automatically, in others the button for distribution will be highlighted and a rule must be set. Last, there may be some instances where a distribution rule will be added to a charge on the inventory -- this is an optional distribution rule and not required.

  • Charge Codes with a Billing ID or Service Number will first apply to the matching service number by the system automatically. If a specific Billing ID or Service Number is referenced on a Charge Code and it no longer exists in the invoice the system will create a record for the Billing ID and distribute the charges.
  • Charges without a reference to a Billing ID or Service Number will always need a rule created and assigned to distribute the charges.

Code Assignment Overview

All Charge Codes must be assigned in the system to proceed with invoice publishing. Proper Charge Code assignment ensures a standardized product structure and enables valuable reporting for customers.

Assignment Process

Charge Code assignment can be completed in two ways:

  1. Individual Assignment

    • Each Charge Code is assigned uniquely to a Charge Code Type, Charge Type and Charge Occurrence

    • A Parent Charge Code can be assigned if applicable

    • The Charge Code Description can be added or updated

  2. Bulk Assignment

    • Multiple Charge Codes can be assigned at once if they share the same Charge Code Type, Charge Type, Occurrence, and Charge Location even if the Charge Codes themselves are differ

      • Account-Level vs. Service-Level
        If a Charge Code appears at both the Account and Service levels, they must be assigned separately:

        • Account-Level requires a distribution code

        • Service-Level typically operates without distribution
          Separate assignments ensure proper configuration for each context despite identical Charge Code values

    • Parent Charge Codes cannot be assigned

    • Charge Code Descriptions cannot be modified

Parent Charge Codes are rare and should only be assigned when two Charge Codes have the same Charge Code but different Charge Code Names.

Distribution Rules for Certain Charge Codes

Some Charge Codes require distribution rules to ensure charges are allocated correctly. These include:

  • Adjustments

  • Account-Level Charges

These charges do not typically total directly to Current Charges provided by the vendor. However, the system considers them part of the Total Current Charges because they must either be paid or used as a credit to offset Current Charges.

  • Charge Codes without a Billing ID always require a distribution rule

  • Charge Codes that reference a Billing ID may also be distributed via a distribution rule

Billing ID & Service Number Matching

  • Charge Codes associated with a Billing ID or Service Number will automatically be applied to the matching service number by the system

  • If a referenced Billing ID or Service Number no longer exists in the invoice, the system will create a record for it and distribute the charges

  • Charges without a Billing ID or Service Number reference will always require a manual distribution rule
