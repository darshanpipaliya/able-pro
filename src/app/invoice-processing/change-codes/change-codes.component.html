Charge Code Assignment

Code Assignment in the UI can be completed in two ways:

  1. Individual Assignment:

    • Each Charge Code is assigned uniquely to a Charge Code Type, Charge Type and Charge Occurrence

    • A Parent Charge Code can be assigned

    • The Charge Code Description can be added or updated

  2. Bulk Assignment:

    • Multiple Charge Codes can be assigned at once if they share the same Charge Code Type, Charge Type, Occurrence, and Charge Location even if the Charge Codes themselves are different

      • Account-Level vs. Service-Level
        If a Charge Code appears at both the Account and Service levels, they must be assigned separately:

        • Account-Level requires a distribution code

        • Service-Level typically operates without distribution
          Separate assignments ensure proper configuration for each context despite identical Charge Code values

    • Parent Charge Codes cannot be assigned when using Bulk Assignment

    • Charge Code Descriptions cannot be added or updated when using Bulk Assignment
