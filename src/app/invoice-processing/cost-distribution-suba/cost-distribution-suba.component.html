Distribution Type refers to the method used in our formula to allocate costs to Billing ID(s) and/or Vendor Product(s). Some Charge Codes—specifically those with a Charge Code Type of Product, Feature, Usage, or Equipment— must be distributed before assigning a Vendor Product, using Billing ID Count or Billing ID Totals. If you have selected to distribute one of these after the Vendor Product assignment, the system will rerun Vendor Products after the rule is created. All other distribution rules can be applied after a Vendor Product is assigned, using Vendor Product Totals as the Distribution Type and do not require the Vendor Product to be recalculated. Other distribution rules can be applied after a Vendor Product is assigned, using Vendor Product Totals as the Distribution Type.

Note: In Step 6, if the selected Distribution Method is Specific Billing ID(s) and you've chosen inventory not included on this invoice, the system will automatically override the Distribution Type to Across All Billing IDs, since there are no charges for the selected Vendor Product from inventory.

Distribution Origin tells the system where to look, in this case the origin account, for the particular charge code that the rule is built against. Basically, where is this charge code showing up on the invoice.

  • Any Account - Rules will look for a specific Charge Code.
  • Any Payable Account - Rules will look for a specific Charge Code that came in on any Payable Account to distribute. This can be used in Distribution Types that are Global. Payable is defined as the account we sent the check for which could be a Main or Sub Account depending on the vendor.
  • Specific Payable Account - Rules will look for a specific Charge Code that came in on a specific Payable Account to distribute. This can only be used with the Distribution Type that is Customer Specific.
  • Any Sub Account - Rules will look for a specific Charge Code that came in on any Sub Account to distribute. This can be used in Distribution Types that are Global.
  • Specific Sub Account - Rules will look for a specific Charge Code that came in on a specific Billing Sub Account to distribute. This can only be used with Distribution Types that are Customer Specific.
  • Any Billing ID - Rules will look for a specific Charge Code that came in on any Billing ID to distribute. This can be used in Distribution Types that are Global.
  • Specific Billing ID - Rules will look for a specific Charge Code that came in on a specific Billing ID to distribute. This can only be used with the Distribution Type that is Customer Specific.
Distribution Origin is required

Distribution Method tells the system where to distribute the Charge Code for the rule.

  1. Payable Account (all inventory/accounts) - This will distribute the specific Charge Code to all Billing ID(s) or Vendor Products in the Payable Account, based on Distribution Type, on a particular invoice. This can be used in Distribution Types that are Global.
  2. Origin Account - This will distribute the specific Charge Code to all Billing ID(s) or Vendor Products, based on Distribution Type, that is tied to the account that the charge originated on. This can be used in Distribution Types that are Global.
  3. Specific Sub Account - This will distribute the specific Charge Code to all Billing ID(s) or Vendor Products, based on Distribution Type, which are tied to that specific Sub Account This can only be used with Distribution Types that are Customer Specific.
  4. Specific Billing ID - This will distribute the specific Charge Code to the specific Billing ID(s) or Vendor Products tied to that Billing ID based on the Distribution Type selected. This can only be used with Distribution Types that are Customer Specific.

    When adding specific billing IDs to a distribution rule, you can select items both from the invoice and from inventory. This includes items that may be associated with the vendor but whose billing IDs are not listed on the invoice. This option ensures that charges are correctly assigned to the appropriate billing IDs.

 Select Billing IDs on Invoice

Select Billing ID's from both the "Select from Invoice" tab and the "Select from Inventory" tabs for your rule.

By opting to include Billing IDs from the inventory that aren't listed on the invoice for a distribution rule, those Billing IDs will be appended to the invoice. Subsequently, they will be allocated a distribution from either the account or another Billing ID in accordance with the Distribution Rule. This allows the customer to see the charges on the Billing ID's they represent vs the Vendors lump sum bill.
