Instructions for Adding Corrections

Charge corrections are necessary when there are missing credits, debits, or partial charges in the invoice details. To address these discrepancies, add the required credits or debits to resolve missing items or balance partial charges. All corrections will be recorded in the system and flagged accordingly.

  1. Compare Charges
    1. Review the itemized charges by Billing ID listed in the invoice system and compare them with the PDF or data files.
    2. When possible, the system will indicate the amount of discrepancy for each Billing ID, helping you identify any missing charges or credits.
  2. Add Missing Charges or Credits
    1. Enter the missing charges or credits on the correction page, along with the appropriate charge code and distribution method.
    2. These entries will be saved in the system, and the difference will be recalculated.
  3. Select Billing IDs for Corrections
    1. Use the checkboxes to select the Billing ID(s) requiring a correction.
    2. For multiple Billing IDs needing the same correction, select one record for each Billing ID. The system will process the correction for each selected Billing ID individually.
  4. Account-Level Charges or Adjustments
    1. To add Account Level Charges or Adjustments, click the Add Correction button.
    2. Enter the charges on the correction page, select the Account Charge Type, assign a charge code, and create a distribution rule for the Account Charge being added.
  5. Limitations
    1. In some cases, the Vendor may not provide totals by Billing ID, making it impossible to display discrepancy information for certain sections. When this occurs, a comprehensive review of all charges will be required. If totals from the Vendor are unavailable, the Difference field will display --.
