Distribution Event
This process involves assigning a Charge Code along with other rule settings that make up a Distribution Rule that then is linked to an Event ID. The distributed charges on the Billing ID will share the same Event ID as the original Distributed Charge. Once the distribution to Billing ID(s) is finalized, the original charge detail record that was distributed is deactivated.
