Rule Conditions

Distribution Level is how the rule will be applied AND where the rules are applied in the sequence listed below. Multiple rules cannot run on a single charge record, the system will only process 1 rule per charge record.

  1. Customer Specific - Rules that are applied to a Specific Customer anywhere when choosing a specific set of value(s) either in Distribution Level or Distribution Method to distribute charges. These value(s) are only present for a particular customer.
  2. Customer Global - Rules that are applied to a Specific Customer but not hold specific value(s) for either Distribution Level or Distribution Method. These rules ONLY affect specific customers that have the specific charge code that the rule applies to.
  3. Vendor Global- Rules that are applied only to Vendor Billing Alias, but we do not hold specific value(s) for either Distribution Level or Distribution Method.  These rules affect ALL customers that have the specific charge code from a Vendor Billing Alias that the rule applies to.

Distribution Type is the method used in our formula for distributing costs to Billing ID(s) and/or Vendor Product(s). Some distributions (Charge Codes with a Charge Code Type of: Product, Feature, Usage or Equipment) must be distributed before a Vendor Product is assigned(Billing ID Count and Billing ID Totals), while other distribution rules can run after a vendor product is assigned and use Vendor Product Totals as the Distribution Type.

The three types of distribution that explain how to distribute the charge:

  1. Vendor Product Totals - This Distribution formula will use the total amount of $ for each Vendor Product that are in the Distribution Method selection within a Distribution Type.
  2. Billing ID Count - This Distribution formula will use the total count of Billing ID’s that are in the Distribution Method selection within a Distribution Type.
  3. Billing ID Totals - This Distribution formula will use the total amount of $ of each Billing ID’s that are in the Distribution Method selection within a Distribution Type.

Distribution Origin tells the system where to look, in this case the origin account, for the particular charge code that the . rule is built against. Basically, where is this charge code showing up on the invoice.

  1. Any Account - Rules with this will look for a specific Charge Code.
  2. Any Payable Account - Rules with this will look for a specific Charge Code that came in on any Payable Account to distribute. This can be used in Distribution Types that are Global. Payable is defined as the account we sent the check for which could be a Main or Sub Account depending on the vendor.
  3. Specific Payable Account - Rules with this will look for a specific Charge Code that came in on a specific Payable Account to distribute. This can only be used with the Distribution Type that is Customer Specific.
  4. Any Sub Account - Rules with this will look for a specific Charge Code that came in on any Sub Account to distribute. This can be used in Distribution Types that are Global.
  5. Specific Sub Account - Rules with this will look for a specific Charge Code that came in on a specific Billing Sub Account to distribute. This can only be used with Distribution Types that are Customer Specific.
  6. Any Billing ID - Rules with this will look for a specific Charge Code that came in on any Billing ID to distribute. This can be used in Distribution Types that are Global.
  7. Specific Billing ID - Rules with this will look for a specific Charge Code that came in on a specific Billing ID to distribute. This can only be used with the Distribution Type that is Customer Specific.

Distribution Method tells the system where to distribute the Charge Code for the rule.

  1. Payable Account (all inventory/accounts) - This will distribute the specific Charge Code to all Billing IDs or Vendor Products in the Payable Account, based on Distribution Type, on a particular invoice. This can be used in Distribution Types that are Global.
  2. Origin Account - This will distribute the specific Charge Code to all Billing IDs or Vendor Products, based on Distribution Type, that is tied to the account that the charge originated on. This can be used in Distribution Types that are Global.
  3. Specific Sub Account - This will distribute the specific Charge Code to all Billing IDs or Vendor Products, based on Distribution Type, which are tied to that specific Sub Account This can only be used with Distribution Types that are Customer Specific.
  4. Specific Billing ID - This will distribute the specific Charge Code to the specific Billing ID(s) or Vendor Products tied to that Billing ID based on the Distribution Type selected. This can only be used with Distribution Types that are Customer Specific.
